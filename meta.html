Current meta

The storm rule and the ZvZ opener. That is the current meta.

High Templar changed how big armies, clumped armies, and medium-HP units should be played. One rule covers most of it.

High Templar changed the game

The current meta has changed heavily because of High Templar. High Templar is now one of the strongest units in the game because storm has a much larger splash radius than before.

Storm changed because its radius was increased, its DPS was decreased significantly, but its duration was extended around 3x. This means storm now punishes huge armies, clumped armies, and medium-HP units much harder over time.

This has caused increased Protoss usage and made High Templar a top-tier meta unit.

The answer is not always “more units”

If your army is dying to High Templar, the answer is not always “build more units.” Sometimes the answer is to spread, bait, buffer, sell, switch tech, or ask a teammate to cover the weakness.

Stop doing this

  • Stop blindly massing Hydras into Protoss.
  • Stop massing Marines into High Templar.
  • Stop gassing early while losing mid.
  • Stop clumping ground armies.
  • Stop upgrading too early before stabilizing army count.

Start doing this

  • Start watching for High Templar earlier.
  • Start spreading Hydras.
  • Start using Roach buffers.
  • Start baiting storm.
  • Start transitioning into Liberators/Ravens as Terran.
  • Start treating Muta as the main ZvZ opener.

ZvZ opener note

The current ZvZ early game is dominated by Muta. Treat Muta as the main opener for the first 6 rounds, then watch for Viper, Hydra, Ultra, and Lurker transition windows.
